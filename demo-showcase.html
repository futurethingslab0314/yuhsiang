📝 每日日記獎勵系統

透過每日寫日記累積獎勵，解鎖專屬紙籤

🚀 立即開始使用
✍️
雙模式輸入
支援文字打字和語音錄音兩種輸入方式，隨時隨地記錄你的心情。
🤖
AI 情緒分析
使用 ChatGPT API 智能分析你的日記內容，根據情緒給予相應獎勵。
🪙
硬幣動畫回饋
每次提交日記都會看到硬幣掉落動畫與音效，給你即時的正向回饋。
📊
進度追蹤
視覺化的進度條顯示你離目標還有多遠，激勵你持續記錄。
🎟️
紙籤列印
達成目標後可列印 AI 生成的專屬任務紙籤，給你實體的成就感。
🎮
互動體驗
支援紅外線感應器模擬投幣動作，帶來遊戲化的互動樂趣。

📖 使用說明

1️⃣ 開始使用

  • 開啟 diary-reward.html
  • 選擇文字或語音輸入模式
  • 撰寫至少 20 字的日記
  • 點擊提交按鈕

2️⃣ 獲得獎勵

  • AI 分析你的情緒與內容
  • 獲得 5-30 枚硬幣
  • 觀看硬幣掉落動畫
  • 查看累積進度

3️⃣ 達成目標

  • 累積 100 枚硬幣
  • 解鎖列印紙籤功能
  • 查看 AI 生成的任務
  • 列印專屬紙籤

4️⃣ 進階功能

  • 整合 Raspberry Pi GPIO
  • 連接紅外線感應器
  • 串接熱感印紙機
  • 自訂獎勵參數

⚡ 快速啟動

Windows 系統

雙擊執行: 啟動日記系統.bat

macOS / Linux / Raspberry Pi

./啟動日記系統.sh # 或 bash 啟動日記系統.sh

手動啟動

python -m http.server 8000 # 然後訪問: http://localhost:8000/diary-reward.html
