🚀 快速開始 (3 步驟)

  步驟 1: 選擇啟動方式
  ┌─────────────────────────────────────────────────────────────┐
  │ Windows 用戶:  雙擊執行 「啟動日記系統.bat」                   │
  │ Mac/Linux:     執行 「bash 啟動日記系統.sh」                  │
  │ 手動啟動:      python -m http.server 8000                   │
  └─────────────────────────────────────────────────────────────┘

  步驟 2: 開啟瀏覽器
  ┌─────────────────────────────────────────────────────────────┐
  │ 訪問: http://localhost:8000/diary-reward.html               │
  │ 或查看功能展示: http://localhost:8000/demo-showcase.html    │
  └─────────────────────────────────────────────────────────────┘

  步驟 3: 開始使用
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. 選擇輸入模式 (文字/語音)                                   │
  │ 2. 撰寫日記 (至少 20 字)                                      │
  │ 3. 點擊提交 → 獲得獎勵！                                      │
  └─────────────────────────────────────────────────────────────┘

📂 技術架構

  前端
  ├─ HTML5               → 語義化結構
  ├─ CSS3                → 動畫、響應式設計、Flexbox/Grid
  ├─ Vanilla JavaScript  → 無框架依賴、ES6+
  └─ Web Speech API      → 語音識別 (可選)

  後端 (可選)
  ├─ Python Flask        → RESTful API 服務
  ├─ python-escpos       → 熱感印紙機驅動
  └─ OpenAI API          → ChatGPT 情緒分析

  硬體 (可選)
  ├─ Raspberry Pi        → 主控板
  ├─ 熱感印紙機          → 58mm/80mm 印紙機
  └─ 紅外線感應器        → GPIO 投幣檢測

🐛 常見問題速查

  Q: 語音識別不工作?
  A: 使用 Chrome/Edge，允許麥克風權限

  Q: 硬幣動畫卡頓?
  A: 限制硬幣數量在 20 個以內

  Q: 如何重置獎勵?
  A: Console 執行: localStorage.clear(); location.reload()

  Q: 音效沒有聲音?
  A: 檢查 sounds/ 資料夾是否有 coin-drop.mp3
