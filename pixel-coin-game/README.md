# 像素硬幣堆疊遊戲

基於 Figma 設計的像素藝術遊戲介面，實現了像素硬幣的物理堆疊效果和語音指示器動畫。

## 功能特色

- 🪙 **像素硬幣堆疊系統**：金色像素硬幣從天而降，自然堆疊形成有趣的圖案
- 🎤 **語音指示器**：右上角的三個白色像素點動畫，模擬語音波形
- 🎮 **遊戲控制**：暫停、清除、加速、重置等功能
- ⌨️ **鍵盤快捷鍵**：支援空格鍵、C、R、S、ESC 等快捷操作
- 📱 **響應式設計**：適配不同螢幕尺寸，支援觸控手勢

## 技術實現

### 物理引擎
- 重力系統：硬幣受重力影響自然下落
- 碰撞檢測：基於網格的精確碰撞檢測
- 堆疊算法：智能尋找最低可用位置進行堆疊

### 視覺效果
- 像素藝術風格：28x28 像素的硬幣和指示器
- 流暢動畫：60fps 的 Canvas 動畫
- 純黑背景：突出金色硬幣的視覺效果

## 使用方法

### 本地運行
```bash
# 方法一：使用 Python
python -m http.server 8000

# 方法二：使用 Node.js serve
npx serve .

# 方法三：使用任何靜態文件服務器
```

然後在瀏覽器中訪問 `http://localhost:8000`

### 遊戲控制

#### 按鈕控制
- **暫停/繼續**：暫停或恢復硬幣生成和動畫
- **清除**：清除畫布上所有硬幣
- **加速**：切換正常速度和雙倍速度
- **重置**：重置遊戲到初始狀態

#### 鍵盤快捷鍵
- `空格鍵`：暫停/繼續遊戲
- `C`：清除所有硬幣
- `R`：重置遊戲
- `S`：切換速度
- `ESC`：暫停遊戲

#### 觸控手勢
- **短按**：暫停/繼續遊戲
- **長按**：清除所有硬幣

## 參數調整

可以在 `pixel-coin-system.js` 中調整以下參數：

```javascript
// 硬幣大小（像素）
this.COIN_SIZE = 28;

// 重力強度
this.GRAVITY = 0.8;

// 硬幣生成間隔（毫秒）
this.SPAWN_INTERVAL = 120;

// 最大硬幣數量
this.MAX_COINS = 150;

// 邊界設定
this.GROUND_Y = this.canvas.height - 100;
this.LEFT_MARGIN = 100;
this.RIGHT_MARGIN = this.canvas.width - 100;
```
