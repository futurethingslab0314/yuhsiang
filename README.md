## 🔧 技術規格

### 硬幣系統
- **大小**: 28px × 28px
- **顏色**: 純金色 (#FFD700)
- **對齊**: 28px 網格對齊
- **堆疊**: 完全堆疊，無重疊

### 動畫效果
- **掉落時間**: 0.8秒
- **彈跳時間**: 0.4秒
- **間隔時間**: 300ms/個
- **旋轉角度**: -360° ~ +360°

### 語音指示器
- **大小**: 28px × 28px
- **顏色**: 純白色 (#FFFFFF)
- **動畫**: 上下彈跳，錯開時間
- **位置**: 右上角 (120px, 120px)
