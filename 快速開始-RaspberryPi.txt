📦 步驟 1: 傳輸檔案到 Raspberry Pi
═══════════════════════════════════════════════════════════════════════

在你的 Windows 電腦上執行 (PowerShell):

  cd C:\Users\geniu\OneDrive\文件\GitHub\yuhsiang
  
  scp diary-reward.html pi@raspberrypi.local:~/
  scp diary-reward-style.css pi@raspberrypi.local:~/
  scp diary-reward-script.js pi@raspberrypi.local:~/
  scp 啟動日記系統.sh pi@raspberrypi.local:~/

⚠️ 如果連線失敗：
   - 替換 raspberrypi.local 為 Raspberry Pi 的 IP 位址
   - 預設密碼: raspberry

═══════════════════════════════════════════════════════════════════════

🔌 步驟 2: 連線到 Raspberry Pi
═══════════════════════════════════════════════════════════════════════

  ssh pi@raspberrypi.local

  (或使用 IP 位址: ssh pi@192.168.1.XXX)

═══════════════════════════════════════════════════════════════════════

🧪 步驟 3: 測試運行
═══════════════════════════════════════════════════════════════════════

在 Raspberry Pi 上執行:

  cd ~
  python3 -m http.server 8000

然後在 Raspberry Pi 的瀏覽器開啟:

  http://localhost:8000/diary-reward.html

或從其他裝置開啟:

  http://[Pi的IP位址]:8000/diary-reward.html

═══════════════════════════════════════════════════════════════════════

🚀 步驟 4: 設定自動啟動 (可選)
═══════════════════════════════════════════════════════════════════════

方法 A - 使用啟動腳本 (簡單):

  chmod +x ~/啟動日記系統.sh
  
  # 編輯自動啟動
  nano ~/.config/lxsession/LXDE-pi/autostart
  
  # 在檔案最後加入:
  @/home/pi/啟動日記系統.sh
  
  # 儲存: Ctrl+X → Y → Enter
  
  # 重啟測試
  sudo reboot

方法 B - 創建啟動腳本 (推薦):

  # 1. 創建啟動腳本
  nano ~/start-diary.sh
  
  # 2. 輸入以下內容:
  
  #!/bin/bash
  sleep 10
  cd /home/pi
  python3 -m http.server 8000 > /dev/null 2>&1 &
  sleep 3
  chromium-browser --kiosk http://localhost:8000/diary-reward.html
  
  # 3. 儲存並設定權限
  chmod +x ~/start-diary.sh
  
  # 4. 設定自動啟動
  nano ~/.config/lxsession/LXDE-pi/autostart
  
  # 5. 加入:
  @/home/pi/start-diary.sh
  
  # 6. 重啟
  sudo reboot

🐛 常見問題快速解決
═══════════════════════════════════════════════════════════════════════

Q: 無法連線到 Raspberry Pi?
A: 1. 檢查是否在同一網路
   2. 啟用 SSH: sudo raspi-config → SSH → Enable
   3. 查看 IP: hostname -I

Q: 網頁無法開啟?
A: 1. 確認伺服器運行: ps aux | grep python
   2. 檢查防火牆: sudo ufw status
   3. 測試: curl http://localhost:8000

Q: Chromium 不會全螢幕?
A: 加入參數: --kiosk --start-fullscreen

Q: 螢幕自動休眠?
A: nano ~/.config/lxsession/LXDE-pi/autostart
   加入:
   @xset s off
   @xset -dpms
   @xset s noblank
